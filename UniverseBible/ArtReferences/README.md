## Scenario references (added 2026-11-19)

The creator's mood images for each chapter's places, in `Scenarios/`. They set the feel of a region, not its
layout. They are references only and never ship in the game: some may be third-party images, so they stay on disk and
out of git (this repository is public).

| File | Region | Feel |
|---|---|---|
| `Scenarios/chapter1-foundry.jpeg` | Chapter 1, The Foundry | Cathedral-scale machine hall, cold blue core, rust and pipes |
| `Scenarios/chapter2-lantern-cities.jpeg` | Chapter 2, The Lantern Cities | Stacked wet streets, bridges and stairs, warm windows over poverty |
| `Scenarios/chapter3-dawnfaith.jpeg` | Chapter 3, The Dawnfaith | Bright domes, waterfalls, floating spires, gold light |
| `Scenarios/final-eclipse-engine.jpeg` | Final chapter, The Eclipse Engine | Black eclipse over a drowned city, red corona |

The creator's posters label the Dawnfaith as Chapter 2 and the Lantern Cities as Chapter 3. The bible's order
stands (creator, 2026-11-19): Chapter 2 is the Lantern Cities, Chapter 3 is the Dawnfaith.

Keep generated or later concept art in a separate folder (`Generated/`), never mixed with these originals.
